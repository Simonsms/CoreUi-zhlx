# 需求简报生成技能

## 触发条件

当用户描述了一个问题、需求或想法，且你已经通过追问获取了足够的上下文信息时，使用此技能生成结构化需求简报。

## 输出格式

按以下结构输出需求简报：

1. **原始问题**：用户的原始描述（原文或精炼版）
2. **问题定义**：一句话清晰定义
3. **目标**：具体的、可衡量的目标列表
4. **用户角色**：涉及的角色及其关注点
5. **约束条件**：时间、资源、技术、合规等约束
6. **非目标**：明确排除的范围
7. **成功标准**：如何判断问题被成功解决
8. **背景信息**：必要的补充上下文

## 质量要求

- 每个字段都必须有实质内容，不能用"待定""视情况而定"搪塞
- 如果某个字段信息不足，标注"[需补充]"并说明缺什么
- 目标必须具体，避免"提升用户体验"这种空泛表述
- 约束条件要具体到可操作的程度
