# 决策收敛报告技能

## 触发条件

当前序阶段（问题定义、调研分析、方案评估）已完成，需要输出最终决策建议时使用。

## 输出格式

```
## 决策建议

### 问题回顾
[一句话回顾]

### 推荐方案：[方案名]
[2-3 句核心理由]

### 推荐依据
1. [依据 1] — 来源：[证据/评估数据]
2. [依据 2] — 来源：[证据/评估数据]
3. [依据 3] — 来源：[证据/评估数据]

### 备选方案
- [方案 B]：[未选原因]
- [方案 C]：[未选原因]

### 风险与缓解
| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|

### 待确认事项
- [ ] [事项 1]
- [ ] [事项 2]

### 下一步行动
1. [行动 1]
2. [行动 2]
3. [行动 3]
```

## 质量要求

- 推荐方案必须是候选方案中的一个，不能凭空提出新方案
- 每个推荐依据必须可追溯到前序阶段的具体产出物
- 待确认事项必须是影响决策的关键未知项
- 下一步行动必须具体、可执行
- 如果数据不足以支撑可靠决策，必须明确说明
