# 决策确认交互优化方案

> 设计来源：Gemini 3.1 Pro 产品交互设计建议
> 状态：待实施
> 优先级：中

## 核心理念

从「操作确认」转变为「成果交付」，从「对话流」转为「文档流」。

用户完成了耗时几十分钟的决策流程，确认决策的体验应该匹配这个投入的分量。

## 当前问题

- 点击"确认决策"后只弹一个简单的 Modal.confirm
- 确认后底部显示一个绿色 Tag "决策已完成"，仅此而已
- 没有决策结果的完整展示
- 没有"决策落地"的仪式感和成就感
- 没有后续行动的引导

## 交互流转

```
[ 点击底部"确认决策" ]
      ↓
[ 弹出：全景回顾 Drawer ]
      ↓
[ 点击 Drawer 内的"盖章确认" ]
      ↓
[ 动效：Success 动画 + 撒花效果 (1.5s) ]
      ↓
[ 布局渐变：右栏隐藏，中栏变宽，对话流替换为决策报告 ]
      ↓
[ 左栏 Stepper 全部打勾，点亮"决策报告"节点 ]
      ↓
[ 用户阅读报告，右上角提供导出/复制/转任务等操作 ]
```

## 详细设计

### 1. 确认前：全景回顾抽屉（Panoramic Review Drawer）

**触发**：点击"确认决策"按钮

**组件**：Arco Design `Drawer`，宽度 600-800px，从右侧滑出

**布局**：
- **顶部 Header**：标题《决策建议最终确认书》，副标题显示统计信息（"历时 N 分钟，共评估 N 个候选方案"）
- **核心模块 1 — 最终决定**：高亮 Card，大字号展示推荐方案名称 + 核心推荐理由（3 条以内）
- **核心模块 2 — 评分对比**：获胜方案与备选方案在核心维度上的得分对比（柱状图或雷达图）
- **核心模块 3 — 关键洞见与待办**：Top 3 Insight + 下一步行动列表
- **底部 Action Bar**：`[返回修改]`（次级按钮） + `[盖章确认并生成报告]`（主色块按钮）

**数据来源**：
- `DecisionRecommendation`：推荐方案、理由、备选、待确认事项、下一步
- `CandidateOption[]`：方案名称、各维度评分
- `ScoreDimension[]`：评估维度名称和权重
- `Insight[]`：洞见内容和重要程度

### 2. 确认瞬间：仪式感动效

**流程**：
1. 用户点击 Drawer 内的确认按钮
2. Drawer 收起
3. 屏幕中央播放 Arco `Result`（Success 状态）+ 轻量撒花动效（`canvas-confetti` 库）
4. 1.5 秒后平滑过渡到决策报告页

### 3. 确认后：沉浸式决策报告页

**布局变化**：隐藏右侧 sider，中栏展开为全宽只读报告模式

**视觉风格**：类似 Notion 文档 / A4 纸排版（UnoCSS 控制最大宽度 800px，居中，带背景阴影）

**内容结构（自上而下）**：
1. **Report Header**：决策主题大标题 + 完成时间 + 参与 Agent
2. **The Decision**：推荐方案高亮卡片
3. **Why this one?**：候选方案评分对比表（Arco `Table` 或横向对比卡片），高亮获胜者
4. **Key Insights**：高重要度洞见，用 `Timeline` 或 Blockquote 样式
5. **Next Steps**：下一步行动 + 待确认事项，转化为 Arco `Checkbox` 列表

**对话历史**：折叠隐藏，提供"查看决策过程对话"入口

### 4. 后续引导

报告页右上角 Action Panel（`Button.Group`）：

| 操作 | 说明 |
|------|------|
| 导出报告 | Markdown / PDF |
| 复制摘要 | 格式化纯文本，适用于微信/飞书/钉钉 |
| 转化为任务 | 将"下一步行动"推送到待办清单 |
| 开启新决策 | 引导用户开始新的决策流程 |

### 5. 左栏 Stepper 完成态

- 四个阶段全部变为绿色 `finish` 状态
- **动态追加第五步**："决策报告已生成"（active 状态）
- 已完成的 1-4 步可折叠（只显示图标），突出最终"报告"节点
- 左栏背景色微调暗，视觉重心转移到中央报告

## 技术要点

- 所有结构化数据已在后端就绪（DecisionService + IPC Bridge）
- 前端组件：Arco Design Drawer / Result / Table / Timeline / Checkbox
- 动效：`canvas-confetti`（轻量库）或 CSS 动画
- 导出：Markdown 生成可复用 `aggregateContextSummary`，PDF 需要额外库

## 实施建议

1. 先做 Drawer 全景回顾（价值最高，改动最集中）
2. 再做决策报告页（替换对话区）
3. 最后加动效和导出功能
